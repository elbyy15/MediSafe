# 💊 MediSafe

MediSafe is a Java Swing based medicine management system designed to manage medicine records and track inventory and expiry information.

## ✨ Features

- Add medicine records
- Search for medicines
- Update medicine details
- Delete medicine records
- Track expiry dates
- Manage medicine quantity
- Manage medicine price
- Display medicine records in a table
- User-friendly graphical interface

## 🛠️ Technologies Used

- Java
- Java Swing
- ArrayList
- LocalDate
- IntelliJ IDEA
